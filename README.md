# MoodMix
An engaging web app that lets users create unique music by mixing their mood, favorite genres, and daily activities. The AI-powered interface generates custom music snippets that users can share, remix, and collect.

Key Features:
- Interactive mood selector with beautiful animations
- Genre mixing interface with real-time preview
- Daily challenges for music creation
- Social sharing and community features
- Progressive Web App support

Tech Stack:
- HTML5, CSS3, JavaScript
- Web Audio API
- Local Storage for saved mixes
- Responsive design for all devices
